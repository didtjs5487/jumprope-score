11-14채점 탭에 색깔별 현황 막대 적용됨

  • 번호 칸 위에 색깔별 인원을 표시: 빨강(A) · 주황(B) · 노랑(C) · 초록(D) · 파랑(E) · 채점 중 · 미응시 · 학적변동 (예: 빨강(A): 8명)
  • 맨 위 줄에 선택한 반의 완료·남은 인원, 맨 아래 줄에 전체 반 합계
  • 알약을 누르면 그 상태의 학생만 번호 칸에서 강조됨(다시 누르면 해제) — 남은 학생을 바로 찾는 용도
  • 채점하면 숫자가 바로 바뀜. 개인진도표 화면에서는 가산점 만점 · 일부 통과 · 아직 없음 기준으로 바뀜. 가로모드 집중 화면에서는 숨김
왜: 누가 끝났고 누가 남았는지를 엑셀이나 시트를 열지 않고 채점 화면에서 바로 보려는 것입니다. 번호 칸 색의 뜻을 따로 외우지 않아도 됩니다.

완료 = 8개 동작을 모두 채점한 학생(등급이 정해진 학생). 채점 중 = 일부 동작만 채점. 미응시 = 아직 채점 기록이 없는 학생. 인원은 명단에 등록된 번호 기준이고 학적변동 학생은 남은 인원에서 뺍니다.

11-09성적이 바뀔 때마다 구글 시트에 자동 반영 적용됨

  • 현황판의 구글 시트로 보내기 단추로 언제든 직접 보낼 수도 있음
  • 명단 탭의 구글 시트 연결 설정 — 주소와 암호를 한 번 저장하면 선생님 계정의 모든 기기에 적용(서버의 선생님 전용 경로에 저장, 학생 접근 없음). 자동 전송 끄기 스위치 있음
  • 시트 쪽은 짧은 Apps Script만 붙이면 됨(서버 열쇠 파일은 쓰지 않음). 암호가 맞을 때만 쓰고, 결과와 거절 이유는 시트의 업데이트 탭에 기록
  • 구글이 앱에 응답을 돌려주지 않는 점(다트 앱에서 확인)에 맞춰 no-cors 방식으로 보냄
  • 설명서 구글시트_연결방법.html, 스크립트 구글시트_스크립트.gs.txt
  • 11-10 추가 — 데이터가 줄어들면 시트를 바꾸지 않음. 앱이 보낼 성적이 지난번에 보낸 것보다 줄었으면(학생·점수 칸 수 기준) 자동 전송을 멈추고 "성적이 지난번보다 줄어서 시트는 그대로 두었습니다" 안내를 띄움. 같거나 늘었으면 보냄(점수를 고친 경우도 반영). 일부러 줄인 경우(새 학기 초기화 등)에는 현황판 구글 시트로 보내기를 직접 눌러 통과시키고 기준을 새로 잡음. 기준은 서버(선생님 전용 경로)에 함께 저장해 한 번도 안 보낸 기기가 줄어든 데이터를 보내는 일도 막음
  • 명단 알림 중 시트 연결 정보만 바뀐 경우에는 채점 화면을 다시 그리지 않도록 함(연타 입력 보호). 48회 연속 누르기에서 버튼 교체 0회 확인
왜: 엑셀을 내려받아 다시 올리는 번거로움을 없애려는 것입니다. 처음에는 서버 열쇠(서비스 계정)로 시트가 서버를 직접 읽는 방식을 만들었지만 설정이 너무 어려워 접고, 다트 앱과 같은 "앱이 보내는" 방식으로 바꿨습니다.

검증: 앱의 내보내기 결과와 시트로 가는 내용이 같음을 가짜 시트 서버로 확인(성적을 바꾸면 1번만 전송, 가만히 있으면 전송 없음, 기기 연결 정보 복원). 받는 스크립트는 가짜 구글 시트 환경에서 암호 확인·탭 생성·옛 반 탭 비우기를 확인. 실제 구글 시트에는 아직 연결해 본 적이 없습니다. 시트에서 직접 고친 내용은 다음 전송 때 덮어써지므로 메모는 다른 탭에 적어야 합니다.

10-29앱 디자인 전면 교체 적용됨

새 색 — 파랑·코랄·민트

연보라 바탕(타바타 앱과 같은 느낌)에서 흰 카드 + 얇은 회선으로 바꿨습니다. 색은 세 가지 일만 합니다.

  • 파랑 = 지금 여기 (현재 동작 · 현재 회차)
  • 코랄 = 실수
  • 민트 = 끝난 것 · 저장됨
왜: 예전 화면은 어두운 바탕에 큰 빨강 덩어리라 무거웠습니다. 색이 하는 일을 셋으로 정리하니 곁눈질로도 "지금 어디"와 "실수"가 구분됩니다.

채점 화면을 채점표(세로 목록)로

동작 하나만 큼지막하게 띄우던 화면을 여덟 동작이 여덟 줄로 늘 함께 보이는 채점표로 바꿨습니다. 지금 차례인 줄만 펼쳐져 실수 버튼이 됩니다.

  • 위로 쓸기 — 펼쳐진 칸을 위로 쓸면 다음 동작, 아래로 쓸면 이전 동작. 목록이 위에서 아래로 내려가는 화면이라 손가락 방향도 같게 맞춤 (옆으로 쓸기도 그대로 동작)
  • 줄 누르기 — 그 동작으로 바로 이동 (예전엔 스와이프를 여러 번 해야 했음)
  • 실수 4회 뒤 한 번 더 — 자동으로 다음 동작 (예전과 같음)
  • 세로로 쓸기는 넣지 않았습니다 — 화면 스크롤과 부딪혀 음악 중에 위험합니다
왜: 음악이 끝났을 때 "무엇을 눌렀고 무엇이 남았는지"를 스크롤 없이 알아야 하기 때문입니다.

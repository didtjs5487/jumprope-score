10-29앱 디자인 전면 교체 적용됨

새 색 — 파랑·코랄·민트

연보라 바탕(타바타 앱과 같은 느낌)에서 흰 카드 + 얇은 회선으로 바꿨습니다. 색은 세 가지 일만 합니다.

  • 파랑 = 지금 여기 (현재 동작 · 현재 회차)
  • 코랄 = 실수
  • 민트 = 끝난 것 · 저장됨
왜: 예전 화면은 어두운 바탕에 큰 빨강 덩어리라 무거웠습니다. 색이 하는 일을 셋으로 정리하니 곁눈질로도 "지금 어디"와 "실수"가 구분됩니다.

채점 화면을 채점표(세로 목록)로

동작 하나만 큼지막하게 띄우던 화면을 여덟 동작이 여덟 줄로 늘 함께 보이는 채점표로 바꿨습니다. 지금 차례인 줄만 펼쳐져 실수 버튼이 됩니다.

  • 옆으로 쓸기 — 다음/이전 동작 (예전과 같은 손동작)
  • 줄 누르기 — 그 동작으로 바로 이동 (예전엔 스와이프를 여러 번 해야 했음)
  • 실수 4회 뒤 한 번 더 — 자동으로 다음 동작 (예전과 같음)
  • 세로로 쓸기는 넣지 않았습니다 — 화면 스크롤과 부딪혀 음악 중에 위험합니다
왜: 음악이 끝났을 때 "무엇을 눌렀고 무엇이 남았는지"를 스크롤 없이 알아야 하기 때문입니다.

회차(재도전) 표시

이름 아래 알약으로 1차 34점 ⭐ 2차 9점 처럼 보입니다. 별표가 성적에 반영되는 최고 회차입니다.

나머지 화면도 같은 색으로

개인진도표 · 2명 동시 채점 · 현황판 · 명단 · 로그인 화면을 같은 색(파랑·코랄·민트)과 간격으로 정리했습니다.

  • 개인진도표 — 채점표와 같은 줄 목록. 통과한 동작은 민트 바탕에 체크
  • 2명 동시 채점 — 같은 색, 되돌리기 버튼을 조용한 흰 버튼으로. 동시에 눌러도 양쪽 기록되는 것은 그대로 확인
  • 이모지를 선 아이콘으로 — 탭·모드 버튼·초기화 버튼·안내 문구까지 모두 같은 굵기의 선 아이콘으로 통일 (기기마다 이모지가 다르게 보이던 문제 해결)
  • 현황판 — 이름이 세로로 꺾이던 표를 한 줄로 고치고 글자 키움, "⏳" 대신 "채점중" 표시, 표는 옆으로 밀어서 봄
  • 로그인 화면 — 새 앱 아이콘 표시
  • 눈이 편하도록 대비 조정 — 회색 보조 글씨를 더 진하게, 초록·빨강을 약간 깊게 바꿔 흰 글씨/흰 바탕에서도 또렷하게 (접근성 기준 4.5:1 통과, 자동 검사로 확인)
  • 글자 크기 — 작은 글씨(11~12px)를 13~16px로 키움 (현황판 머리·요약줄·명단 안내문 등)

모션 — 상태가 바뀐 순간에만

  • 실수를 누르면 칸이 통통 튀며 채워지고, 점수 숫자가 한 번 튀고, 버튼 둘레에 코랄 파문이 번짐
  • 동작을 넘기면 펼쳐진 줄이 위에서 살짝 내려오며 열림
  • 8개를 모두 채점하면 빛이 한 번 훑고 지나감
  • 개인진도표에서 통과를 누르면 체크가 톡 찍힘
  • 버튼은 누를 때 살짝 눌렸다 돌아오고, 카드는 부드럽게 나타남
안전장치: 모션은 색·투명도·크기만 바꾸고 화면을 다시 그리지 않습니다. 빠르게 연타하거나 두 손가락으로 동시에 눌러도 입력이 씹히지 않는 것을 시험으로 확인했습니다. 폰의 "동작 줄이기" 설정을 켜 두면 모션이 꺼집니다.

번호 칸 등급 색

A 빨강 · B 주황 · C 노랑 · D 초록 · E 파랑, 아직 평가를 안 본 학생은 흰 칸. 완성도Ⓐ만 반영하고 개인진도표(가산점)는 색에 넣지 않습니다.

등급 기준은 평가계획서에 없어 완성도Ⓐ(40점)에 성취평가 비율(90·80·70·60%)을 적용했습니다 — 36↑A, 32↑B, 28↑C, 24↑D, 그 아래 E. 학교 기준이 다르면 바꿀 수 있습니다.
